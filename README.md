# 🎵 Spotify Clone

A web-based music player application that mimics the core features of Spotify. Built with HTML, CSS, and JavaScript, this clone allows users to play, pause, and navigate through a playlist of songs with a sleek interface. 🎶

## ✨ Features

- 🎶 **Song Playlist**: Displays a list of songs with cover images and metadata.
- ▶️ **Play/Pause Controls**: Interactive buttons to control music playback.
- 📊 **Progress Bar**: Seek through the current song using a draggable progress bar.
- ⏭️ **Next/Previous Navigation**: Skip to the next or previous song in the playlist.
- 🎨 **Visual Feedback**: Animated GIF and icons for an engaging user experience.
- 📱 **Responsive Design**: Optimized for various screen sizes.

## 🛠️ Technologies Used

- 🌐 **HTML**: Structure of the web page.
- 🎨 **CSS**: Styling and layout (refer to `style.css`).
- ⚙️ **JavaScript**: Functionality for audio playback and user interactions (refer to `script.js`).
- 🎯 **Font Awesome**: Icons for play, pause, and navigation buttons.

## 🚀 How to Run

1. 📥 **Clone or Download**: Ensure all project files are in the same directory.
2. 🌐 **Open in Browser**: Open `index.html` in any modern web browser.
3. ▶️ **Start Playing**: Click on a song in the list or use the play button to begin playback.

### 📋 Prerequisites

- 🌍 A web browser (e.g., Chrome, Firefox, Safari).
- 🔊 Ensure audio files in the `songs/` folder and images in `covers/` are accessible.
